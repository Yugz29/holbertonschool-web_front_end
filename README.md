# Holberton School Web Front End

## Overview

This repository contains my projects from the **Web Front End specialization** of the Holberton School curriculum.

The focus is on mastering **HTML and CSS fundamentals**, building well-structured, semantic, and responsive web pages from scratch. This repo demonstrates a progressive learning path from advanced HTML structures to CSS styling and layouts.

---

## Project Structure

| Folder          | Description                                              |
| --------------- | -------------------------------------------------------- |
| `html_advanced` | Advanced HTML5 structure and semantic markup             |
| `CSS_advanced`  | Advanced CSS styling, layouts, and responsive techniques |

Each folder contains exercises and example files demonstrating specific frontend concepts. They follow an incremental approach to build real-world-ready pages.

---

## Skills Covered

* Writing valid and semantic **HTML5**
* Structuring content for readability and accessibility
* Advanced **CSS** selectors, layouts (Flexbox, Grid), and styling techniques
* Responsive design and media queries
* Linking reusable styles to HTML components
* Preparing pages for future enhancements such as JavaScript integration

---

## How To Use

1. Clone this repository:

```sh
git clone https://github.com/Yugz29/holbertonschool-web_front_end.git
```

2. Open any folder (e.g., `html_advanced/`) and browse the `.html` files in a browser
3. Review the `.css` files to see styles applied
4. Follow the incremental numbered files to see step-by-step progress
