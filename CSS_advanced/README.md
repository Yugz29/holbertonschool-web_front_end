# CSS Advanced (Holberton School Web Front End)

## Overview

This directory contains **advanced CSS projects and exercises** from the Holberton School Web Front End curriculum.

The focus is on deepening CSS skills beyond basics, including layout, styling techniques, selectors, and responsive design essential for modern web development.

Key focus areas include:

* CSS selector specificity and combinators
* Box model mastery (margin, padding, border, content)
* Advanced layout techniques (Flexbox, Grid)
* Typography and font management
* Styling navigation, lists, tables, and forms
* Pseudo-classes and pseudo-elements
* Responsive design principles
* Visual enhancements with transitions and animations

---

## Files and Structure

| File / Folder            | Purpose                                                          |
| ------------------------ | ---------------------------------------------------------------- |
| `.css` stylesheets       | Styles applied to HTML pages from html_advanced or other modules |
| Layout examples          | Demonstrate advanced positioning and structure                   |
| Responsive examples      | Show CSS handling for different screen sizes                     |
| Utilities and components | Reusable classes and styling patterns                            |

---

## Example Snippet

```css
nav ul {
  display: flex;
  gap: 1rem;
}

nav a:hover {
  color: #007acc;
  transition: color 0.3s ease;
}
```

This snippet demonstrates Flexbox layout and pseudo-class hover effects.

---

## Best Practices Demonstrated

* Use external stylesheets linked via `<link rel="stylesheet">`
* Semantic class names for clarity and maintainability
* Separation of content (HTML) and presentation (CSS)
* Mobile-first and responsive design via media queries
* State-based styling with pseudo-classes (`:hover`, `:focus`, etc.)
