# HTML Advanced (Holberton School Web Front End)

## Overview

This directory contains **advanced HTML projects** from the Holberton School Web Front End curriculum.

The goal is to build **semantic and well-structured HTML pages** demonstrating mastery of modern HTML5 concepts and best practices.

Focus areas include:

* Correct HTML5 document structure
* Semantic elements (`header`, `footer`, `main`, `section`, `article`, `nav`, `aside`)
* Proper use of headings, lists, tables, quotes, and media
* Accessibility basics and W3C compliance

---

## Files and Structure

| File                            | Purpose                                                         |
| ------------------------------- | --------------------------------------------------------------- |
| `0-index.html`                  | Initial basic HTML skeleton                                     |
| `1-index.html` → `9-index.html` | Incremental tasks building page structure and content           |
| `about.html`, `contact.html`    | Additional content pages and navigation examples                |
| `styleguide.html`               | Demonstrates formatting, media, and semantic elements           |
| `index.html`                    | Final polished page with navigation, sections, and social links |
| Media folder                    | Images, audio, and video used in the HTML pages                 |

> Numbered files show step-by-step progression from simple pages to advanced, semantically rich structures.

## Example Snippet

```html
<header>
  <nav>
    <ul>
      <li><a href="#">Home</a></li>
      <li><a href="#">About</a></li>
    </ul>
  </nav>
</header>
<main>
  <section id="hero">
    <h2>Welcome to My Portfolio</h2>
  </section>
  <section id="services">
    <h2>Services</h2>
  </section>
</main>
<footer>
  <ul>
    <li><a href="#">Facebook</a></li>
    <li><a href="#">Twitter</a></li>
  </ul>
</footer>
```

---

## Best Practices Demonstrated

* Start with `<!DOCTYPE html>`
* Use proper heading hierarchy (`<h1>` → `<h2>` → `<h3>`)
* Group related content with `<section>` and `<article>`
* Use `<nav>` for page navigation
* Separate content and structure (no CSS or JS at this stage)
